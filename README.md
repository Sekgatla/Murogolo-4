# Murogolo Primary School Website

A static, GitHub Pages-compatible website for Murogolo Primary School. The redesign uses a premium editorial direction with forest green, navy, warm cream and gold, while retaining the supplied school identity and activity photographs.

## Project files

All website files and image files are kept together in the project root. There are no `assets/`, `images/`, `css/` or `js/` subfolders.

```text
school-murogolo-main/
├── index.html
├── about.html
├── curriculum.html
├── admissions.html
├── donate.html
├── contact.html
├── style.css
├── script.js
├── logo-crest.png
├── logo.jpg
├── school.jpg
├── athletics.jpg
├── netball.jpg
├── soccer.jpg
└── speech.jpg
```

## Publish with GitHub Pages

1. Extract the ZIP.
2. Upload the contents of `school-murogolo-main/` to the root of your GitHub repository. Keep `index.html` at the repository root.
3. Commit and push to the branch/folder configured in **Settings → Pages**.
4. After deployment, open the published website and test all pages, navigation, forms and 3D features.

## Notes

- CSS is consolidated in `style.css`; JavaScript and the embedded crest data are consolidated in `script.js`.
- The pages currently use Tailwind CSS, Font Awesome and Three.js from CDNs, so those features require an internet connection.
- Confirm school contact details, location pin, dates, statistics and payment configuration before publishing.
- Illustrative content must not be presented as verified Murogolo facilities or achievements.
